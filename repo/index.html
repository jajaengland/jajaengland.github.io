Receptor 1.8.0b1

Safari downloads, file browser and APT package manager for 32-bit iOS 4-8; experimental beta.

Targets rootful 32-bit iOS 4.0–8.x (below 9.0); iOS 7–8 experimental. Optional background desktop access requires both apps at 1.8.0 beta 1, explicit fingerprint-confirmed device setup, Windows sharing running and reachable Wi-Fi. Grants unattended package/source changes while locked, with desktop transaction confirmation. Only Receptor’s download folder is remotely exposed. Close Cydia before changes; APT uses system networking/TLS. Host integration tests pass; physical-device launchd, locked Wi-Fi, root/mobile permissions and package/source operations need validation. Earlier user reports cover iPad 1 / iOS 5.1.1 and iPad 4 / iOS 6.1.3; feature coverage remains incomplete.

Experimental 1.8.0 background access beta — desktop packages/sources and encrypted download-folder transfers; device testing pending
